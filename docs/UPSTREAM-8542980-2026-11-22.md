## Build/package toolchain

The macOS host has no Homebrew LLVM, so the package step uses local wrappers
outside this repository:

- `clang`/`lld-link` from the Xcode/Rust toolchains
- a COFF `llvm-lib` writer with both linker members and an `llvm-nm` symbol index
- `llvm-rc` no-op and an ELF/Mach-O `llvm-objcopy` for `-O binary`/symbol edits

With those, the EDK2 CLANGPDB `UniXNU` package, payload and boot image all
build. The 160 MiB payload was reduced to 128 MiB for the initrd bound.
